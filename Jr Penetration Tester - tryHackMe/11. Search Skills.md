# Vulnerability Database (CVE)

>[!quote] Definition
> **Common Vulnerabilities and Exposures** (CVE), this term is given to a publicly disclosed vulnerability

Each confirmed vulnerability is assigned a unique identifier in the format `CVE-YEAR-NUMBER`, such as `CVE-2025-55182`

>**Common Vulnerability Scoring System** (CVSS) an open framework used to measure and assign a numerical severity score to software and system vulnerabilities based on a variety of factors, such as:
- **Impact -** What damage can this vulnerability lead to?
- **Complexity** - Is the vulnerability easy to exploit or not? 
- **Availability** - How likely is it that someone can exploit this?

Websites like [ExploitDB](https://www.exploit-db.com/) compile this information alongside "Proof of Concepts" (PoCs), which are scripts capable of demonstrating the vulnerability.
