# Shodan
`a search engine for the Internet of Things (IoT)`
>[Shodan](https://www.shodan.io/) continuously scans the internet, searching for networking equipment, industrial control systems, traffic cameras, and virtually anything else with a public network connection to see what's running and where.

# Vulnerability Database (CVE)

>[!quote] Definition
> **Common Vulnerabilities and Exposures** (CVE), this term is given to a publicly disclosed vulnerability

Each confirmed vulnerability is assigned a unique identifier in the format `CVE-YEAR-NUMBER`, such as `CVE-2025-55182`
