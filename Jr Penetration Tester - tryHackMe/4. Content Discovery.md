>[!quote] Definition
>Content is whatever material you can use in your mission, either intended to be hidden from the public or not

## 3 main ways to discover content: 

### Manually

#### Robot.txt
> The robots.txt file is a document that tells search engines which pages they are and aren't allowed to show on their search engine results or ban specific search engines from crawling the website altogether.
> 
> in the list of restrictions there might be locations the owner of the website doesn't want us to discover

#### Favicon
>Sometimes when frameworks are used to build a website, a favicon that is part of the installation gets leftover, and if the website developer doesn't replace this with a custom one, this can give us a clue on what framework is in use.
>
>[This is a database provided from OWASP for the favicon](https://wiki.owasp.org/index.php/OWASP_favicon_database)

Below is a command line to get the md5 Hash of the favicon
```
 curl https://static-labs.tryhackme.cloud/sites/favicon/images/favicon.ico | md5sum
```

#### Sitemap.xml

> it's the opposite of the robots.txt 
> this is a list of all files the website owner wishes to be listed on a search engine
> maybe there is older pages that are no longer in use but still works
