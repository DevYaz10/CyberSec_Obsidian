>[!quote]- Definition
> File inclusion is a web vulnerability occurring when an application improperly sanitizes user input, allowing attackers to manipulate file paths to include, read, or execute unauthorized files on the server. Local File Inclusion (LFI) targets local files, while Remote File Inclusion (RFI) executes external files, both potentially leading to Remote Code Execution (RCE) and sensitive data exposure.


## Path Traversal

>[!quote]- Definition
> Path traversal vulnerabilities occur when the user's input is passed to a function such as file_get_contents in PHP. It's important to note that the function is not the main contributor to the vulnerability. Often poor input validation or filtering is the cause of the vulnerability. In PHP, you can use the file_get_contents to read the content of a file.
